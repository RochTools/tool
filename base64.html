What is Base64?

What it does
Converts binary data into text using 64 printable ASCII characters (A–Z, a–z, 0–9, +, /). Safe to transmit over text-only systems.
Common uses
Embed images in HTML/CSS, HTTP Basic Auth headers, JWT tokens, email attachments (MIME), JSON/XML data fields.
URL-Safe variant
Replaces + with - and / with _ so the string is safe in URLs, query params, and JWT tokens without extra encoding.
Privacy
Everything runs in your browser. No data is sent to any server. Base64 is encoding, not encryption — anyone can decode it.
