# RochTools

## Overview

**RochTools** is a comprehensive collection of professional tools designed for creators. All tools run entirely in your browser with zero data upload to any server. Everything is completely free and requires no sign-up.

## Key Features

- 100% browser-based tools
- Zero server uploads (all processing happens locally)
- Completely free to use
- No registration or login required
- Instant access to all features

## Available Tools

### 1. Video Downloader
Download HD videos from popular platforms without watermarks
- Support for YouTube, Facebook, and TikTok
- No watermark HD downloads
- 100% browser-side processing
- Zero data upload

### 2. Password Generator
Create strong, secure passwords instantly
- Generate customizable passwords with adjustable length
- Choose from multiple character types
- Built-in strength meter
- 100% browser-side - zero data upload

### 3. QR Code Generator & Scanner
Generate and scan QR codes instantly
- Create QR codes from text or URLs
- Scan QR codes directly from images or camera
- Real-time processing
- 100% browser-side, zero data upload

### 4. Word Counter
Count and analyze text in real-time
- Word, character, and sentence counting
- Paragraph and sentence analysis
- Reading time estimation
- Keyword frequency analysis
- 100% browser-side - zero data upload

### 5. Color Picker
Pick, preview, and copy colors instantly
- Live color preview functionality
- Get HEX, RGB, and HSL codes with one-click copy
- Save color history (last 20 colors)
- 100% browser-side

### 6. Base64 Encoder/Decoder
Convert text and files to Base64 and decode instantly
- Text to Base64 conversion
- File to Base64 conversion
- Base64 to text decoding
- Runs fully in your browser
